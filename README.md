## 一些印象比较深的项目

### K230 + STM32 图像识别与双目视觉

路径：

```text
24252/CNN_basedon_k230&stm32/
```

这是较早期的嵌入式视觉学习项目之一，主要涉及 K230、STM32、目标检测以及双目视觉。

其中 K230 部分包含双摄像头的采集、显示和目标检测流程，并在此基础上继续处理目标位置、距离和角度等信息。

这个项目对我个人比较重要的一点，是当时所使用的平台并没有直接提供满足需求的双目实现。为了让两个摄像头能够真正同时工作，我查阅了大量资料，并对原有流程进行了修改和重新组织，最终实现了自己的双目方案。

它也是我第一次真正体会到：

> 当现成的库和官方实现不能解决问题时，可以继续向下理解系统，并自己补上缺失的部分。

相关代码目前仍保留在仓库中，作为当时学习嵌入式视觉、K230 和双目系统的一份记录。

### 多光束干涉与碳化硅外延层厚度反演

路径：

```text
25261/B题/
25261/Complex function/
```

这一部分最初来源于一个具体的光学建模问题：利用干涉信息反演碳化硅外延层厚度。

学习过程中，从基础的干涉模型逐渐推进到多光束干涉，并进一步尝试从复变函数的角度重新理解和描述这一问题。

目前保留了两份阶段性成果：

* 《基于递进式光学干涉模型的碳化硅外延层厚度反演问题研究》
* 《复变函数视角下的碳化硅外延层干涉厚度反演》

对我而言，这一部分的意义不只是完成一次建模，而是第一次比较清楚地感受到：

> 一个具体的物理问题，可以随着数学工具的深入，被不断重新表达和重新理解。
