# 基于 K230 与 STM32 的嵌入式双目视觉识别与控制系统

这是一个基于 **K230 + STM32F103** 搭建的嵌入式视觉与控制系统。

项目最初以 YOLO 目标检测和 K230 嵌入式部署为切入点，随后逐步扩展为一个包含：

- 双目视觉
- 目标检测
- 深度估计
- 云台追踪
- K230 与 STM32 上下位机通信
- OLED 信息显示
- 蓝牙遥控小车

的完整软硬件系统。

本项目最终完成了实际硬件搭建和运行验证，而不仅停留在算法或仿真阶段。

## 双目视觉实现

项目中比较重要的一部分是 **K230 双目视觉的实现**。

K230 在当前运行条件下并不适合同时对两个摄像头分别运行完整的神经网络推理，因此本项目采用了一种更轻量的方案：

1. 左侧摄像头运行 YOLO 目标检测；
2. 获得目标检测框；
3. 从左目图像中提取目标区域；
4. 在右目对应搜索区域中进行模板匹配；
5. 得到右目目标位置；
6. 根据左右目标中心的视差计算深度。

核心关系为：

```text
depth = baseline × focal_length / disparity
```

其中：

- `baseline`：双目摄像头基线距离
- `focal_length`：像素单位下的焦距
- `disparity`：左右图像中目标位置的视差

这种方法避免了同时运行两个神经网络模型，在有限硬件资源下实现了双目标跟踪与深度估计。

## YOLO 模型部署

视觉部分主要使用 YOLO 系列模型。

基本流程为：

```text
数据采集
   ↓
数据标注
   ↓
YOLO 模型训练
   ↓
PT / ONNX
   ↓
模型量化与转换
   ↓
KModel
   ↓
K230 KPU 推理
```

在 K230 端，图像经过：

```text
图像采集
   ↓
AI2D 预处理
   ↓
KPU 推理
   ↓
后处理
   ↓
NMS / 检测框解析
   ↓
OSD 绘制
```

最终得到目标类别、置信度、检测框等信息。

## 云台目标追踪

视觉模块得到目标位置后，会计算目标相对于图像中心的偏移角度。

根据当前云台位置计算新的目标角度，并使用平滑处理逐步调整舵机：

```text
目标位置
   ↓
像素偏差
   ↓
角度偏差
   ↓
目标舵机角度
   ↓
低通 / 平滑处理
   ↓
二维云台运动
```

系统能够使摄像头云台持续跟踪目标。

## K230 与 STM32 通信

K230 和 STM32 之间通过 USART 建立通信。

K230 发送的数据包括：

- 目标中心坐标
- 目标宽高
- 目标深度
- 目标角度

数据帧采用自定义协议：

```text
0xFF
  +
Length
  +
Data
  +
0xFE
```

STM32 接收到数据后进行解析，并存入结构体中供后续功能调用。

## 项目特点

这个项目对我而言不仅是一次嵌入式课程实践。

最开始只是希望学习计算机视觉和 YOLO 的基本流程，但在实际搭建过程中逐渐遇到了：

- K230 多摄像头处理限制
- 双目实时处理资源不足
- 模型部署与量化
- 图像显示与推理资源冲突
- 双目匹配
- 深度估计
- 上下位机通信
- 机械结构稳定性
- 电机和外围设备控制

等问题。

其中双目部分并没有直接可用的完整实现，因此通过阅读 API、测试摄像头通道和显示图层，并结合模板匹配方法，最终完成了能够实际运行的双目视觉方案。

从模型训练、部署，到嵌入式视觉，再到 STM32 控制和最终实物搭建，这也是我较早完成的一次相对完整的软硬件系统实践。
