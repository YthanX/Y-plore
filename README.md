## K230 + STM32 图像识别与双目视觉

**时间：2025.03 – 2025.06**

这是较早期的一次完整嵌入式视觉实践，主要涉及 K230、STM32、目标检测以及双目视觉。

其中 K230 部分包含双摄像头采集、显示和目标检测流程，并在此基础上继续处理目标位置、距离和角度等信息；STM32 负责下位控制与外围设备交互。项目最终完成了实际硬件搭建，而不仅停留在算法验证阶段。

这个项目对我个人比较重要的一点，是当时所使用的平台并没有直接提供满足需求的双目实现。为了让两个摄像头真正同时工作，我查阅了大量资料，并对原有流程进行修改和重新组织，最终实现了自己的双目方案。

同期保留的 `Stereo Color Blob Experiments` 是双目系统前期的测试代码，主要用于验证双摄像头、色块识别、显示与串口通信等基础功能。

> 当现成的库和官方实现不能解决问题时，可以继续向下理解系统，并自己补上缺失的部分。

## 多光束干涉与碳化硅外延层厚度反演

**时间：2025.06 – 2025.10**

这一部分最初来源于一个具体的光学建模问题：利用干涉信息反演碳化硅外延层厚度。

学习过程中，从基础干涉模型逐渐推进到多光束干涉，并形成阶段性研究结果。

在 **2025.10 左右**，又进一步尝试从复变函数 / 复分析的角度重新理解和描述这一问题。

目前保留的阶段性成果包括：

- 《基于递进式光学干涉模型的碳化硅外延层厚度反演问题研究》
- 《复变函数视角下的碳化硅外延层干涉厚度反演》

> 一个具体的物理问题，可以随着数学工具的深入，被不断重新表达和重新理解。

## STM32F103RCT6 拍频项目

**时间：2026.02 – 2026.06**

基于 STM32F103RCT6 的拍频信号采集、测量与显示课程设计。

工程主要使用嵌入式 C，包含：

- ADC / DMA 数据采集
- 拍频信号处理
- 串口调试与数据输出
- 按键与编码器交互
- 显示界面
- 应用层任务调度

该项目保留完整的 Keil 工程、STM32F10x 标准外设库、启动文件与应用层代码。
