# K230 双目色块识别测试

这是一个用于测试 **K230 双摄像头采集与色块识别** 的简单实验目录。

主要用于验证后续双目视觉项目所需的基础功能，包括：

- 两路摄像头同时采集图像
- 左右画面同时显示
- 基于 LAB 阈值进行色块识别
- 获取左右目色块的位置与尺寸
- 串口输出识别结果
- 按键控制识别启停
- LED 状态提示

### `双目色块代码`

主要测试程序。

程序同时初始化 K230 的两个摄像头，并将左右图像分别显示在屏幕两侧。

代码中预设了红、绿、蓝三组 LAB 色彩阈值；当前实际使用的是 **蓝色色块识别**。程序会分别寻找左右画面中面积最大的目标色块，并绘制矩形框和中心点。

识别后可获得：

```text
中心点 x / y
色块宽度 / 高度
当前帧率
```

这些信息会通过 UART 串口输出，为后续双目匹配、深度计算和上下位机通信测试提供基础数据。

## 当前流程

```text
左摄像头 ──→ 色块识别 ──→ 左目目标位置 ─┐
                                           ├─→ 串口输出 / 后续双目计算
右摄像头 ──→ 色块识别 ──→ 右目目标位置 ─┘
```

显示端使用 1280×720 画面，将两路 640×480 摄像头图像左右排列显示。

## 说明

这个目录属于后续 **K230 + STM32 双目视觉项目** 的早期测试代码，主要用于确认双摄像头同时工作、色块检测、显示和串口通信等基础功能是否可行。

代码中已经预留了深度和角度计算函数，但当前版本尚未将其真正整合进双目深度估计流程。
